# Telegram Doctor Bot (Go)

## Описание

Порт примера ConversationHandler из python-telegram-bot на Go. Персистентность — файловая JSON.

## Как подготовить

1. Получите токен у @BotFather
2. Создайте тестовую группу/чат для проверки

## Запуск локально (без Docker)

```bash
export TELEGRAM_TOKEN="ВАШ_ТОКЕН"
go run .
```
